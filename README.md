## 🐟 3DFish

Parametric modeling of a 3D fish using geometric primitives, rendered with OpenGL.

### Features
- Parametric 3D fish model built from geometric primitives
- Texture mapping (scales, fins, water background)

### Tech Stack
- **Language:** C++
- **Graphics:** OpenGL
- **IDE/Build:** Code::Blocks

### Getting Started

**Prerequisites:**
- Code::Blocks IDE
- OpenGL libraries installed (e.g., freeglut/GLUT)

**Run the project:**

1. Clone the repository to your local machine
2. Open `Projet.cbp` in Code::Blocks and build/run the project.
